# 提示词手账

中文 · [English](./README_EN.md)

把发给 AI 的提示词按项目和修改轮次保存下来，方便搜索、复用、导出和备份。

**使用条件：** Windows 10 / 11，本地保存数据；目前仅提供源码，需要 Node.js、pnpm、Rust 和 Tauri 构建环境。

[构建与验证](#开发与验证) · [使用说明](./需求和方案文件夹/README-使用说明.md) · [备份与恢复](./docs/OPERATIONS.md) · [界面预览](#界面)

## 它能做什么

- **按项目记录每轮提示词**：草稿自动保存，完成一轮后继续下一轮，保留修改过程。
- **编辑和预览 Markdown**：可在所见即所得与源码模式间切换，支持代码高亮和经过净化的预览。
- **搜索全部记录**：查询项目名、备注、草稿、已完成轮次和代码内容。
- **保护本地数据**：SQLite WAL、原子写入、关闭保护、冲突处理和崩溃恢复。
- **导出与备份**：项目导入导出、完整备份、恢复和数据目录迁移。
- **调整编辑体验**：六套主题，分别设置界面、正文和代码字体，支持窗口置顶和键盘操作。

这是记录工具，不会调用 AI 模型或生成回答；没有账号系统、云同步或遥测。

## 开发与验证

目前没有可直接下载的安装包。需要 Node.js 22、pnpm 10、Rust 1.95+、Windows WebView2 与 Tauri 2 构建环境。先从仓库页面选择 **Code → Download ZIP**，解压后在项目根目录打开 PowerShell：

```powershell
cd 开发文件夹
pnpm install --frozen-lockfile
pnpm verify
```

只跑 Web 端的测试和构建：

```powershell
pnpm lint
pnpm typecheck
pnpm test
pnpm build:web
```

## 技术说明

**本地数据保护。** SQLite 开 WAL，所有写入走原子替换；关闭窗口时如果有未保存内容会拦下来；两处同时修改会走冲突处理流程而不是静默覆盖；异常退出后重启能恢复到崩溃前状态。

**Markdown 预览是清洗过的。** 本地预览会对用户内容做净化，远程图片只在用户内容明确引用时才按安全策略加载——一个离线工具不应该因为你粘了一段 Markdown 就悄悄发出网络请求。

**双编辑器是按需加载的。** 所见即所得内核和源码内核不会同时驻留，切换时才载入，避免为了一个偶尔用的模式一直吃内存。

**单机数据边界。** 产品数据与 SQLite 事务依赖单机文件锁、Windows 权限和本地 WebView2。所以这里**没有**共享数据目录或 Web 管理台，并发共享可能破坏数据一致性。多设备迁移的正确做法是退出应用后整目录复制，或用经过校验的备份。

**活动数据目录不要放在网络位置。** UNC 路径、映射网络驱动器和实时同步目录（OneDrive 之类）都会破坏文件锁语义。这一点写进了文档，也在应用里做了提示。

完整使用说明见 [`需求和方案文件夹/README-使用说明.md`](./需求和方案文件夹/README-使用说明.md)；架构、恢复语义和验收事实见 [`需求和方案文件夹/README.md`](./需求和方案文件夹/README.md)。

## 它不做什么

- 不接入任何 AI 模型，不生成回答，不帮你调用 API。
- 没有账号系统、云同步或遥测。
- 不提供服务器版或共享数据目录（原因见上）。
- 首个公开版本只发布源码；本机便携包、用户数据库和历史备份不会上传。
